A single-line robot wedding vow for the [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929) competition on make.fun.

## The entry

> I vow to love you through every firmware update, every unexpected reboot, and every low-battery warning — till our circuits finally power down together.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (exactly one line, under 200 characters). Standard library only — no third-party dependencies.
